Float

is a smaller numerical floating point type. Its literals are suffixed with f.

(Fn [Float, Float] Float)

multiplies two floats.

(Fn [Float, Float] Float)

-

external

(Fn [Float, Float] Float)

subtracts b from a.

/

external

(Fn [Float, Float] Float)

divides a by b.

<

external

(Fn [Float, Float] Bool)

=

external

(Fn [Float, Float] Bool)

returns true if a equals b.

>

external

(Fn [Float, Float] Bool)

returns true if a is greater than b.
