IO.Raw

Wrappers for functions from the C standard library. Consider using a more carpesque function from IO when it exists. For detailed documentation please consult the documentation of your system (e.g. under Linux try man fprint).

EOF

external

Int

A signal indicating the End-Of-File has been reached. Wraps EOF from the C standard library

O-RDONLY

external

Int

Read-only flag for open.

SEEK-CUR

external

Int

When passed to fseek designates the reference position as the current position in the file. Wraps SEEK_CUR from the C standard library.

SEEK-END

external

Int

When passed to fseek, designates the reference position as the end of a FILE (EOF). Wraps SEEK_END from the C standard library.

SEEK-SET

external

Int

When passed to fseek designates the reference position as the beginning of the file. Wrpas SEEK_SET from the C standard library.

fclose

external

(Fn [(Ptr FILE)] Int)

Closes the FILE associated with the given file pointer. Returns an integer indicating success or failure. Wraps fclose from the C standard library.

feof

external

(Fn [(Ptr FILE)] Bool)

Returns true if the position indicator for the given FILE is at the end of file EOF. Wraps feof from the C standard library.

ferror

external

(Fn [(Ptr FILE)] Bool)

Returns true if an error indicator is set for the given FILE. Wraps ferror from the C standard library.

fflush

external

(Fn [(Ptr FILE)] Int)

Flushes buffered data associated with a given FILE pointer. For files in write mode, writes all buffered data to the file. For files in read mode, discards all unused data in the buffer. If the FILE pointer is NULL, flushes all open ouput streams. Returns an integer indicating success or failure. Wraps fflush from the C standard library.

fflush!

defn

(Fn [(Ptr FILE)] ()) 

                        (fflush! file)

Flushes buffered data via fflush , but discards the result, making this function appropraite for use as a side effect in do forms.

fileno

                        (fopen pathname mode)

Low-level routine to open a file for input/output/appending. Wraps fopen from the C standard library. Consider using the function IO.open-file instead.

fputc

external

Writes a character to a FILE Wraps fputc from the C standard library.

fread

(Fn [(Ref String a), Int, Int, (Ptr FILE)] Int) 

                        (fread file-name item-size items-count file)

Reads a given numebr of bytes from a file into C-String. Wraps fread from the C standard library. Consider using read-file or unsafe-read-file instead.

fseek

external

(Fn [(Ptr FILE), Int, Int] Int)

Sets the position indicator of a FILE based on a given reference position and offset. The position indicator will be set to an offset number of bytes from the reference position. Valid reference positions are SEEK-SET, SEEK-CUR, and SEEK-END.

Returns an integer indicating success or failure. Wraps fseek from the C standard library.

fseek!

external

(Fn [(Ptr FILE), Int, Int] ())

Sets the position indicator of a FILE via fseek, but discards the result, making this function appropriate for use as a side effect in do forms.

fstat-size

external

(Fn [Int] Long)

Returns the size in bytes of an open file descriptor, or -1 on error.

open

external

(Fn [(Ref String a), Int] Int)

Opens a file at path with the given flags (e.g. IO.Raw.O-RDONLY). Returns a raw file descriptor, or -1 on error.

rewind

external

(Fn [(Ptr FILE)] ())

Sets the stream position indicator associated with a FILE pointer back to the beginning of the file. Wraps rewind from the C standard library. To verify that resetting the position succeeded, use fseek instead.

unlink

defn

(Fn [(Ref String a)] Int) 

                        (unlink file-name)

Removes the named link to a file from the filesystem. If this is the last link to the file, and no process has the file open, deletes the underlying file. If the argument designates a symbolic link, deletes the link only. Returns an integer indicating success or failure. Wraps unlink from the POSIX api in <unistd.h>). See the POSIX API documentation for more information.

unlink!

defn

(Fn [(Ref String a)] ()) 

                        (unlink! file-name)

Deletes a file link via unlink, but discards the result, making this function appropriate for use as a side effect in do forms.
